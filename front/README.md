# AI Scientist 原型系统 · 基于国产开源大模型（Qwen）的多智能体科学假设生成闭环

> 参考《揭榜挂帅》赛题「基于国产开源大模型的 AI Scientist 研发与应用」，以「人工智能」选题板块 **118–125 号议题**为对象，构建：
> ① 可视化项目流程框架；② 可回答人工智能议题的 **AI Agent 原型**（离线可答 + 可选 Qwen 真实调用）。

---

## 一、它解决什么问题

赛题要求系统产出**「真且可验」**的科学假设，并满足四大能力项：文献挖掘与事实提取、逻辑驱动假设生成、论证可行与多轮迭代、智能体思辨与人在回路。本原型用一条**四层十一阶段流水线** + **三重闸门迭代闭环**把这套要求落成可演示的产品。

## 二、核心特性

- **可视化流程框架**（Tab ①）：输入层 / 认知层 / 生成层 / 校验层 / 输出层 / 支撑层六泳道架构图，点击任意节点查看职责；附赛题评分标准对照表与关键模块实现要点。
- **AI 议题问答 Agent**（Tab ②）：内置 118–125 号 8 个前沿议题真实证据库，**带文献编号溯源**，区分「已验证共识 / 存在争议 / 研究空白」，一键转入假设生成流水线。
- **多智能体假设生成流水线**（Tab ③）：S1–S11 实时动画 + 逐阶段日志，三重闸门不通过即回传重写。
- **《科学假设与研究计划》10 字段输出**（Tab ④）：待研究问题 / 解决思路 / 技术手段 / 数据集 / 标题 / 摘要 / 方法论 / 实验设计 / 实验结果 / 参考论文，支持 Markdown / JSON / 打印导出。
- **真实文献索引库 R1–R47**：严禁虚构引用，启动即做引用完整性自检。
- **浏览器内统计引擎**：Pearson 相关、Welch t 检验、Cohen's d、不完全贝塔函数求双侧 p 值——统计量对数据**实时真实计算**，非预写死数字。
- **双模式**：离线演示模式（内置证据库 + 本地统计，无需联网即可完整跑通闭环）/ Qwen 真实模式（阿里云百炼 OpenAI 兼容 API）。

## 四、运行

**离线演示模式（默认，无需 Key）：**
```bash
cd prototype
node server.js            # 默认 5173 端口
# 浏览器打开 http://localhost:5173
```

**Qwen 真实模式（阿里云百炼）：**
1. 点击右上角「模型配置」，填入百炼 / DashScope API Key，选择模型（qwen-plus / max / turbo / qwen3-max）。
2. 若浏览器直连被 CORS 拦截：把「接口地址」改为 `/api`，由 `server.js` 代理转发（密钥不出本机）。

**自检：**
```bash
node selftest.js          # 期望 13/13 通过，8 议题三重闸门全 ✓
```

## 五、三重闸门（迭代闭环的核心）

| 闸门 | 阶段 | 校验内容 | 不通过动作 |
|---|---|---|---|
| 双辩论对抗 | S6 | 反方有效论据数量（阈值可配）；反方意见分「外部效度类 / 内在机制类」 | 范围收窄消解前者，后者正面回应；回传 S5 重写 |
| 原文溯源校验 | S7 | 引用完整性（权威闸门＝零虚构）+ 前提—原文贴合度（辅助信号） | 虚构引用回传补全；贴合不足补强「原文锚定」 |
| 因果量化检验 | S8 | 相关性与分组显著性、效应量 | 数据不支持即否决；弱关联强制降级为「弱关联」 |

> **关键设计点（S7）**：用「新假设文本」去比对文献必然重合度≈0——假设本应新颖。因此溯源环节校验的是**假设的文献前提**（共识/争议/空白陈述绑定的真实文献），权威闸门＝引用完整性（零虚构引用）；字符级 Jaccard 仅作「引用贴合松紧」的辅助信号，低重合≠错误引用（可能只是改写表述），不作为通过/失败判据。

## 六、赛题能力项 / 评分标准对照

- 文献挖掘与事实提取 → S2（无来源即丢弃，从源头压幻觉）
- 逻辑驱动假设生成 → S4 跨域迁移 + S5 归纳+演绎
- 论证可行与多轮迭代 → S6/S7/S8 三重闸门闭环，最多 3 轮
- 智能体思辨与人在回路 → S6 双辩论 + S9 人工约束注入
- 评分标准（科学价值 40 / 技术深度 30 / 应用潜力 30）→ S11 七维度自评面板逐项留痕
